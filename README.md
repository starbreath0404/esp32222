# 雙手手勢翻譯系統

RT-Thread MicroPython 版本的完整架構請見 `RT-Thread_MicroPython_獨立運行設計.md`。

## 新電腦第一次執行

1. 安裝 64 位元 Python 3.11 或 3.12，並勾選 `Add python.exe to PATH`。
2. 雙擊 `01_安裝環境.cmd`。
3. 安裝完成後，雙擊 `02_啟動錄製工具.cmd`。

完整搬移說明請見 `在其他電腦執行_零基礎版.md`。不要把舊電腦的 `.venv` 搬到新電腦。

目前先完成不依賴硬體的手勢辨識核心。每個取樣點包含左右手各 14 個特徵：

- 5 個彎曲感測值
- MPU9250 的 3 軸加速度、3 軸陀螺儀、3 軸磁力計

雙手合併後，每個取樣點共有 28 維。系統以 50 Hz 錄製約 2 秒的時間序列，再使用 DTW（動態時間校正）比較不同速度的相同動作。

## 執行示範

雙擊 `02_啟動錄製工具.cmd` 即可開啟正式錄製介面。

示範程式會產生模擬感測資料、錄製三種手勢範本，並測試已知與未知動作。

## 執行測試

```powershell
& '.\.venv\Scripts\python.exe' '.\micropython\tests\test_core.py'
```

## 後續硬體整合

1. 左右手 ESP32-S3 各自讀取 5 個 Flex 與 MPU9250。
2. 左手以 ESP-NOW 傳送 14 維資料、封包序號與時間戳。
3. 右手把左右資料同步後，透過 USB 序列埠輸出 28 維資料。
4. 將序列埠資料接入 `GestureRecorder`。
5. 演算法確認穩定後，再移植到右手 ESP32-S3 並連接 WAV 播放。
